# Datos

Copia aquí el archivo del curso:

```
data/MEDIQA-CORR-2024-MS-TrainingData.csv
```

Es el set de entrenamiento MS de MEDIQA-CORR 2024 (2.189 notas, 1.219 con error), parte del benchmark MEDEC.
No se sube al repositorio porque el benchmark no publica una licencia de redistribución.
Fuente: [github.com/abachaa/MEDEC](https://github.com/abachaa/MEDEC) · [MEDIQA-CORR-2024](https://github.com/abachaa/MEDIQA-CORR-2024).

Columnas usadas: `Text ID`, `Text`, `Sentences`, `Error Flag`, `Error Sentence ID`, `Error Sentence`, `Corrected Sentence`, `Corrected Text`.
